# Power-Market-Trading-Strategy-Analysis
Analysis of day-ahead and intraday power auction data (Spot, ID1, ID2, ID3) to identify a systematic, rule-based trading strategy under a 1 MWh flat-position mandate. This project is deliberately not a predictive-modeling exercise. The goal is not to forecast the level of future spreads with a regression or ML model, but to determine, from the statistical structure of the data alone, when and in which direction a systematic, exploitable bias exists between sequential auctions and to turn that into a simple, auditable trading rule.
